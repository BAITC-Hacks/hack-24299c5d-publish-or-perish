# Географическая основа Астаны

Карта использует опубликованный муниципальным геопорталом **архивный слой пяти районов**, до выделения Сарайшыка. Это географические контуры, а не сгенерированная иллюстрация. Точную дату действия границ сервер не сообщает; карта не заявляется актуальной административной картой на 2026 год.

Источник границ: https://gis.esaulet.kz/server/rest/services/Hosted/Adm_raiony/FeatureServer/0

Запрос: `/query?where=1%3D1&outFields=*&outSR=4326&f=pjson`.

Снимок сохранён 23.09.2026 в `astana-districts-source.json`. Шесть объектов источника соответствуют **пяти названиям** районов: Байконур состоит из двух объектов. Группировка выполняется по `name_object`, поскольку поле `region` для Нуры содержит прежнее название Есиль. Исходные контуры не объединялись с современным слоем шести районов.

Реки: https://gis.esaulet.kz/server/rest/services/Hosted/hydrography_12092022/FeatureServer/65

Запрос аналогичный, формат `json`; локальный снимок `astana-rivers-source.json`. Геометрия рек обрезается по границам города при отображении. Слой гидрографии датирован в названии 12.09.2022.

Преобразование в SVG: `node data/build-map.cjs` из корня проекта. Координаты WGS84 преобразуются в локальную равнопромежуточную проекцию с опорной широтой 51.15°, север сверху, пропорции сохраняются. Результат — `assets/astana-map-data.js`. Игра читает этот модуль локально, обращения к геопорталу при запуске не нужны.

Значки мероприятий размещаются внутри соответствующего района и обозначают **игровые проекты, а не реальные адреса строительства**. Значки всех 14 мероприятий различаются. Показатели районов остаются синтетическими из задания хакатона.

На карте размещена ссылка на геопортал. Метаданные сервиса не содержат отдельной лицензии (`copyrightText` пуст); источник указан без заявления об открытой лицензии.
