# Локальный запуск и размещение сайта

Браузер отправляет запросы на относительный путь `/api/analyze`. Страницы и API
работают на одном домене как локально, так и на хостинге. Менять `analysis.js` не нужно.
Оба режима используют `serve-local.js` и `analysis-api.js`.

## На этом компьютере

В PowerShell выполните `./start-local.ps1`, откройте http://127.0.0.1:8765/.
Настройки `OPENAI_API_KEY` и `OPENAI_MODEL` находятся в `.env.local`.

## На хостинге с Docker

Подключите репозиторий к сервису, который запускает Dockerfile, или соберите образ:

```sh
docker build -t akim-city .
```

Задайте в панели хостинга переменные окружения:

| Переменная | Значение |
| --- | --- |
| `OPENAI_API_KEY` | Секретный ключ, только в хранилище секретов хостинга |
| `OPENAI_MODEL` | `gpt-4.1-mini` либо доступная вам модель Responses API |
| `PUBLIC_ORIGIN` | Полный внешний адрес сайта, например `https://city.example.com`, без пути |
| `PORT` | Порт приложения, по умолчанию `8000` |

Направьте HTTPS-домен на порт приложения. Настройте таймаут прокси не менее 75 секунд:
обработчик ждёт OpenAI до 60 секунд. Для проверки состояния используйте `GET /api/status`.
Значение `configured: true` говорит о наличии настроек, а не о проверке ключа в OpenAI.

Для запуска образа на своём сервере передайте значения из окружения оболочки:

```sh
docker run --rm -p 8000:8000 -e OPENAI_API_KEY -e OPENAI_MODEL -e PUBLIC_ORIGIN akim-city
```

Файлы `.env*` исключены из Docker-образа. Хостинг читает секреты из окружения,
не из локального файла. Сайт раздаёт только разрешённые файлы.

## На сервере с Deno без Docker

Задайте те же переменные окружения и выполните:

```sh
deno run --no-config --no-lock --no-prompt --allow-read=. --allow-env=OPENAI_API_KEY,OPENAI_MODEL,PUBLIC_ORIGIN,PORT --allow-net serve-hosted.js
```

Процесс слушает `0.0.0.0`, поэтому доступен прокси хостинга. Локальный скрипт
по-прежнему слушает только `127.0.0.1`. `PUBLIC_ORIGIN` позволяет корректно принимать
запросы с внешнего HTTPS-домена за прокси, не доверяя произвольным заголовкам прокси.

## Ограничения размещения

GitHub Pages и обычная статическая раздача HTML не запускают серверный API.
Для анализа нужен описанный серверный режим. Node.js и сборка браузерных модулей не нужны.
Секретный ключ нельзя добавлять в браузерный JavaScript.

Основа настройки: [Deno и Docker](https://docs.deno.com/runtime/reference/docker/),
[переменные окружения Deno](https://docs.deno.com/runtime/reference/env_variables/).
