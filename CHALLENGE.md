# Второй режим: восемь кварталов

Независимый модуль `challenge.js` импортирует исходные мероприятия и веса из `score.js`. Основной режим не меняется. Для проверки откройте `/challenge-demo.html` через локальный сервер. Автопроверки: `node challenge.test.mjs`.

Игровой экран второго режима оформлен в стиле основного: `challenge-demo.html`, `assets/challenge-ui.js`, `assets/challenge.css` и общие стили `assets/game.css`. На карте выбирается район; справа доступны текущие показатели и прогноз. Между кварталами открывается окно с двумя событиями и фактическим изменением бюджета. Изображения карт подключаются из `assets/cards/M1.webp` … `M14.webp`, при отсутствии остаются заглушки. Основной экран не редактировался.

## Правила C1

- Кварталов 8. В начале 40 бюджета, затем +15 при переходах в кварталы 2–8. Остаток сохраняется.
- Базовая рука 5 различных мероприятий. Между кварталами приходят **два разных события**. Изменения руки складываются: +2 и −1 дают 6 карт. Предел 1–10, а при истощении пула — доступное число мероприятий.
- Карта разыгрывается один раз за ход. Неразыгранные карты возвращаются в пул. Районные проекты могут повторяться в разных районах в последующие ходы; городские — только один раз за игру.
- Сохраняются несовместимости исходного датасета. Лимиты пяти решений и двух мер направления в этом режиме сняты. Ход можно пропускать, покупки окончательны.
- Два денежные события складываются перед списанием; бюджет ограничен снизу нулём. Затем начисляется плановое финансирование +15. Показывается фактическое изменение бюджета.
- Скидки/наценки одного направления складываются в множитель (−25% и +20% = 0.95). Цена округляется до ближайшей целой единицы, минимум 1. Модификаторы руки и цен действуют только в новом квартале, прошлые сбрасываются. Межквартальное событие не меняет цену уже купленного проекта.
- После восьмого квартала не выдаются события, карты и доход.

## Время и оценка

Для проекта, купленного в квартале Q, вклад на конец квартала T равен `полный эффект × max(0, T − (Q − 1) − лаг) / 8`. Прогноз использует T=8. Текущее состояние во время хода показывает конец предыдущего квартала, после финала — конец восьмого. Это накопленный эффект в рамках условной модели датасета, не физический прогноз.

Синергия применяется после появления положительного эффекта обеих мер и действует в районе первой меры пары. При повторах первой меры в разных районах каждый получает свой бонус. Суммы ограничиваются диапазоном 0–100 после всех эффектов. Формула Score и веса прежние. Итоги основного режима и испытания не сравниваются напрямую.

## Контракт для интерфейса

```js
import { createChallenge } from './challenge.js';
const game = createChallenge({ seed: 'TEAM-42' });
game.subscribe(state => render(state)); // сразу и после успешных операций
const preview = game.previewPlay({ id: 'M7', district: 'Нура' });
if (preview.allowed) game.play({ id: 'M7', district: 'Нура' });
const { transition, state } = game.endTurn();
```

`getState()` возвращает независимую копию: `quarter`, `budget`, `finished`, `hand` (карты с `currentCost`), `projects` (с кварталом и уплаченной ценой), `events` (два активных события), `conditions`, `current`, `forecast`, `history`. У `conditions.budget` значение после событий до дохода; для доступных средств используйте верхнеуровневое `budget`. `previewPlay()` возвращает `allowed`, `errors`, `cost`, `remainingBudget`, `forecast`, `scoreDelta`, `warning`. Невалидная операция возвращает `ok:false`, не изменяя игру. Предпросмотр не расходует случайность.

Переход возвращает фактическую дельту бюджета от событий и отдельный доход. Покажите обе карточки событий, прежде чем отображать новую руку. Ошибки отображайте текстом; предупреждение о слишком позднем проекте показывайте до покупки.

Код испытания задаёт последовательность событий и приоритетов колоды. При одинаковых решениях игры совпадают полностью; при разных решениях набор доступных проектов отличается, поэтому руки могут отличаться. Код не содержит решений и не заменяет код результата. AI-анализ и экспорт результатов второго режима пока не подключены.
