# Аким на 5 часов — Publish or Perish

Браузерный калькулятор для интерактивного выбора мероприятий по условиям хакатона. Все вычисления выполняются в обычном JavaScript на стороне клиента. Сервер Node.js, `require`, пакеты и сборка не нужны.

## Файлы и запуск

- `score.js` — независимый от интерфейса модуль ES: данные, расчёт, ограничения, прогнозы, подсказки и подписка на изменения.
- `scenario-picker.js` — готовый компонент для подключения к DOM сайта.
- `scenario-picker.css` — оформление, серые недоступные варианты и подсказки при наведении или фокусе.
- `example.html` — рабочий пример выбора мероприятий.
- `checks.html` и `score.checks.js` — проверки логики и взаимодействия с интерфейсом в браузере.
- `analysis.js` — отправка подтверждённого набора и кодов сравнения на API сайта.
- `analysis-api.js` — серверный обработчик анализа ИИ на стандартном JavaScript, без Node.js.
- `analysis.checks.js` — проверки API с подменой сети, без платных запросов.

Разместите файлы на обычном статическом HTTP-сервере или в проекте сайта и откройте `example.html`. Модули ES подключаются через `<script type="module">`; открытие через `file://` может блокироваться браузером. Проверки доступны на `checks.html` того же сервера.

## Подключение к главному модулю

```js
import { createScenario } from './score.js';

const scenario = createScenario();

// Обработчик сразу получает начальное состояние и затем каждое успешное изменение.
const unsubscribe = scenario.subscribe((state, event) => {
  updateScore(state.result.score); // Ваша функция обновления балла на странице.
  updateBudget(state.result.remainingBudget);
  updateOptions(state.options);
  // state.canFinalize разрешает получение итогового результата.
  // event.type: init, add, remove, replace или reset.
});

// Обработчик выбора районного мероприятия:
const operation = scenario.add({ id: 'M10', district: 'Нура' });
if (!operation.ok) showErrors(operation.errors);

// Для городского мероприятия district не передаётся.
scenario.add({ id: 'M12' });

// Прогноз без изменения выбора и без уведомления подписчиков:
const addition = scenario.previewAdd({ id: 'M8', district: 'Нура' });
if (addition.allowed) showPreview(addition.score, addition.delta);

const removal = scenario.previewRemove('M10');
if (removal.allowed) showPreview(removal.score, removal.delta);

scenario.remove('M10'); // Удаляет эффекты и синергию, обновляет доступность вариантов.

// Для смены района или восстановления сохранённого набора:
scenario.setDecisions([{ id: 'M10', district: 'Алматы' }]);

const finalResult = scenario.finalize();
if (!finalResult.valid) showErrors(finalResult.errors);

// При удалении компонента страницы:
unsubscribe();
```

Функции `updateScore`, `updateBudget`, `updateOptions`, `showPreview`, `showErrors` в этом примере принадлежат главному модулю сайта. Готовое подключение без этих функций показано ниже.

`add`, `remove`, `setDecisions` и `reset` возвращают `{ ok, errors, issues, state }`. Невалидная операция не меняет состояние и не вызывает подписчиков. Снимки состояния и справочники защищены от изменения; для обновления используйте методы хранилища. `getState()` возвращает актуальный снимок, `reset()` очищает выбор.

## Предварительный и итоговый баллы

При выборе от нуля до четырёх мероприятий показывается **предварительный** балл. При пяти допустимых мероприятиях — итоговый. Ограничения бюджета, повторов, районов, направлений и совместимости действуют на любом этапе.

Чистый расчёт без хранилища:

```js
import { calculateScore } from './score.js';

const preview = calculateScore(
  [{ id: 'M10', district: 'Нура' }],
  { allowIncomplete: true },
);
const finalResult = calculateScore(fiveDecisions); // Ровно пять решений.
```

Недопустимый расчёт возвращает `valid: false`, `score: null`, `errors` и структурированные `issues`. Недопустимый прогноз имеет `allowed: false`, `score: null`, `delta: null`. Балл запрещённого набора не показывается как допустимый результат. Остаток бюджета не даёт бонуса.

Данные, 14 мероприятий, лаги, веса и синергии взяты из PDF «Датасет районов». Эффекты складываются с исходными значениями, после чего показатели ограничиваются диапазоном 0–100. Штраф применяется к каждому показателю строго ниже 40. Порядок выбора не влияет на результат. Удаление всегда пересчитывает результат от исходных данных.

Базовый балл, вычисленный по исходным показателям, — **52,55768**; в документе он округлён до **52,56**. `baselineScore` и дельты используют точное значение, `publishedBaselineScore` хранит округлённое значение из документа. Округление производится только при отображении.

Пример из документа: M7, M8, M10 в Нуре; M12 для города; M5 в Сарыарке. Стоимость **95**, итог **56,54307**, синергия M10 + M12 добавляет B1 +2 в Нуре.

## Серые варианты и прогноз каждой операции

`state.options` содержит все 54 варианта: районные меры в каждом из пяти районов и четыре городские меры.

| Поле варианта | Значение |
| --- | --- |
| `key` | Стабильный ключ, например `M7:Нура` или `M12:city` |
| `decision` | Объект для передачи в `scenario.add()` |
| `selected` | Выбран ли именно этот вариант |
| `action` | `add` или `remove` |
| `disabled` | Заблокирована ли операция |
| `reasons`, `issues` | Причины блокировки на русском и их коды |
| `preview.score`, `preview.delta` | Балл после операции и изменение относительно текущего выбора |
| `synergyHints` | Подсказки о действующих и возможных синергиях |

Для выбранного варианта прогноз относится к **удалению**, для остальных — к **добавлению**. Удаление остаётся доступным при заполнении всех пяти мест. Повторный выбор одной меры в другом районе запрещён. Все ограничения пересчитываются после каждой успешной операции.

- M4 + M7 запрещены только в одном районе: M4 в Нуре делает M7 в Нуре серым, другие районы остаются доступны при соблюдении остальных ограничений.
- M5 + M13 работают по такому же правилу.
- M1 + M3 запрещены **во всех районах**, как указано в документе.
- После удаления блокировка снимается, если нет других причин: бюджета, лимита пяти мер, повторов или лимита двух мер в направлении.

## Подсказки о синергиях

Подсказка учитывает выбранный набор, рассматриваемую меру и район бонуса. `hint.text` — готовый русский текст для наведения или клавиатурного фокуса. Значения `hint.status`:

- `active` — сочетание уже выбрано, бонус действует;
- `ready` — добавление этого варианта включит бонус;
- `potential` — можно добавить недостающую меру для получения бонуса;
- `blocked` — сочетание существует, но текущие ограничения не позволяют его собрать; причины включены в текст.

Поддерживаются M1 + M2 → T1 +2 в районе M1; M10 + M12 → B1 +2 в районе M10; M5 + M6 → E2 +2 в районе M5. Бонус не масштабируется лагом. Для отдельной подсказки доступна функция `getSynergyHints(decisions, candidate)`.

## Готовый компонент страницы

```html
<link rel="stylesheet" href="./scenario-picker.css">
<div id="measures"></div>
<script type="module">
  import { mountScenarioPicker } from './scenario-picker.js';
  const root = document.getElementById('measures');

  // Установите слушатель до подключения, чтобы получить и начальное состояние.
  root.addEventListener('scenariochange', ({ detail }) => {
    console.log('Текущий балл:', detail.state.result.score);
  });
  root.addEventListener('scenariofinalize', ({ detail }) => {
    console.log('Итоговый балл:', detail.score);
  });

  const component = mountScenarioPicker(root);
  // component.scenario — доступ к хранилищу.
  // component.destroy() — удаление компонента и отписка.
</script>
```

Можно передать существующее хранилище: `mountScenarioPicker(root, { scenario })`. Компонент обновляет серые кнопки, прогнозы и подсказки автоматически. Недоступные варианты имеют фокусируемую обёртку для чтения причины блокировки с клавиатуры. События `scenariochange` и `scenariofinalize` всплывают к главному модулю.

## Данные результата для объяснений

`districts` содержит итоговые показатели, их изменения (`deltas`), оценки и критические показатели районов. `weightedAverage`, `minimumDistrictScore`, `criticalCount`, `criticalPenalty` раскрывают части формулы. `synergies` перечисляет применённые бонусы. `contributions` содержит эффекты каждой меры с учётом лага до ограничения диапазоном 0–100; это изменения показателей, а не независимые вклады в итоговый балл, поскольку минимум и штраф нелинейны.

## Анализ ИИ после подтверждения

Короткое подключение в главном модуле сайта:

```js
import { analyzeScenario } from './analysis.js';

root.addEventListener('scenariofinalize', async () => {
  try {
    const { decisions } = component.scenario.getState();
    const result = await analyzeScenario(decisions, otherCodes);
    output.textContent = result.analysis;
  } catch (error) {
    output.textContent = error.message;
  }
});
```

`component` — результат `mountScenarioPicker(root)`, `otherCodes` — массив кодов других участников. В `example.html` уже подключены ввод кодов, отправка после подтверждения пяти мер, защита от повторного щелчка и отмена устаревшего ответа при изменении выбора.

Код примера из документа: **`A1:5.2,7.4,8.4,10.4,12`**. `encodeScenario(decisions)` создаёт код, `decodeScenario(code)` восстанавливает и проверяет набор. После точки указан район: 0 — Есиль, 1 — Алматы, 2 — Сарыарка, 3 — Байконур, 4 — Нура; городские меры записываются без района. Порядок выбора на код не влияет. Префикс `A1` обозначает текущую версию правил. Код описывает выбор и не является подтверждением личности или официальным результатом участника.

Для запросов ИИ подключите `handleAnalysis(request, env)` из `analysis-api.js` к маршруту **POST `/api/analyze`** на том же домене. Обработчик использует стандартные `Request`, `Response`, `fetch`; его экспорт по умолчанию совместим с модульным Worker. В серверной среде задайте секрет `OPENAI_API_KEY` и переменную `OPENAI_MODEL` с доступной вашей команде моделью Responses API. В браузер ключ не передаётся. Обычный статический сервер запускает калькулятор, но сам не реализует маршрут анализа.

Запрос: `{ code, otherCodes }`, максимум 10 кодов сравнения. Сервер проверяет все коды и пересчитывает баллы, удаляет повторы и собственный код из сравнения, затем запрашивает краткий анализ на русском. В ответе: `{ code, score, comparisons, analysis }`; `differenceFromCurrent` означает балл другого набора минус текущий. При отсутствии чужих кодов ИИ объясняет только текущий набор. Ошибки возвращаются как `{ error }` со статусом 400, 502 или 503. Общие настройки авторизации и ограничения частоты запросов предоставляет основной сервер сайта.

Используется [OpenAI Responses API](https://developers.openai.com/api/docs/guides/text); реальные запросы требуют настроенного серверного ключа. Браузерные проверки подменяют API и не расходуют средства.
