# hack-24299c5d-publish-or-perish
Репозиторий команды Publish or Perish для хакатона.

## Калькулятор качества жизни города

`score.js` рассчитывает итоговый балл качества жизни Астаны для симулятора «Аким на 5 часов». Исходные значения районов, каталог мероприятий, ограничения, лаги, синергии и формула взяты из документов хакатона. Для запуска нужен Node.js; дополнительные библиотеки не требуются.

Запустите пример сценария из датасета:

```sh
node score.js
```

В консоли появится отчёт на русском языке: итоговый балл, расходы, показатели районов, штрафы, синергии и эффекты мероприятий.

Пример использования из другого файла JavaScript:

```js
const { calculateScore } = require('./score');

const result = calculateScore([
  { id: 'M7', district: 'Нура' },
  { id: 'M8', district: 'Нура' },
  { id: 'M10', district: 'Нура' },
  { id: 'M12' },
  { id: 'M5', district: 'Сарыарка' },
]);

if (!result.valid) {
  console.error(result.errors);
} else {
  console.log('Итоговый балл:', result.score);
}
```

Сценарий должен содержать ровно пять разных мероприятий. Для районных мер укажите `district`: `Есиль`, `Алматы`, `Сарыарка`, `Байконур` или `Нура`. Для городских мер (`M2`, `M6`, `M12`, `M14`) поле `district` следует опустить.

Бюджет составляет 100 единиц; допускается не более двух мероприятий одного направления. Несовместимые пары проверяются по правилам датасета. Невалидный сценарий возвращает `valid: false` и массив `errors` с причинами на русском языке; итоговый балл не рассчитывается.

Названия функций и полей программного интерфейса сохраняют исходное написание для подключения к другим компонентам. Все сообщения, названия мероприятий, комментарии и консольный отчёт написаны по-русски.

| Поле результата | Значение |
| --- | --- |
| `valid` | Допустимость сценария |
| `errors` | Причины отклонения невалидного сценария |
| `cost`, `remainingBudget` | Стоимость и остаток бюджета |
| `score` | Итоговый балл |
| `districts` | Показатели и оценки районов после применения мер |
| `weightedAverage` | Средняя оценка с учётом долей населения |
| `minimumDistrictScore` | Оценка самого слабого района |
| `criticalCount`, `criticalPenalty` | Число показателей строго ниже 40 и штраф |
| `baselineScore` | Округлённый базовый балл из документа: 52,56 |
| `scoreChangeFromBaseline` | Разница с базовым баллом из документа |
| `synergies` | Применённые бонусы за сочетания мероприятий |
| `contributions` | Эффекты каждой меры с учётом лага, до ограничения диапазоном 0–100 |
